# نظام إدارة الدروس الخصوصية

نظام ويب متكامل واحترافي لإدارة **مراكز الدروس الخصوصية** و**المدرسين الخصوصيين**.
يوفر النظام موقعاً إلكترونياً باسم سنترك أو اسمك كمدرس، يجمع بين لوحة تحكم كاملة للمدير
وبوابة عامة وحسابات خاصة للطلاب، مع حفظ كل البيانات بأمان على السحابة (Supabase).

> النظام ليس مخصصاً لمعلم بعينه — بل هو منتج جاهز لأي سنتر أو مدرس.
> يكفي أن تكتب «اسم المدرس / السنتر» في الإعدادات حتى يُعاد تسمية الموقع بالكامل باسمك.

---

## أهم المميزات

### لوحة تحكم المدير
- **الصفوف والمجموعات والمواعيد:** إنشاء الصفوف الدراسية، وعدة مجموعات داخل كل صف
  بأيامها وأوقاتها وأسعارها، ونشر الجدول الأسبوعي وتصديره PDF.
- **الطلاب:** قاعدة بيانات كاملة، موافقة على طلبات التسجيل، نقل بين المجموعات، إيقاف/حظر، وإنشاء حسابات.
- **طلبات الطلاب:** تسجيل، نقل، واستفسارات/رسائل، مع إشعار بعدد الطلبات الجديدة.
- **التحصيل الشهري:** استحقاقات ورسوم ودفعات، حساب تلقائي للمتأخرات والرصيد وتقارير مالية.
- **الاختبارات:** أوراق اختبار ورقية قابلة للطباعة/PDF، واختبارات إلكترونية بتصحيح تلقائي ونتائج فورية.
- **الحضور والغياب:** تسجيل الجلسات وحساب نسب الحضور لكل طالب.
- **التقارير:** تقارير المستوى والدرجات والحضور والتحصيل، وتقرير فردي لكل طالب.
- **الإعلانات ولوحة الشرف:** إعلانات عامة، تكريم المتفوقين، ملفات ومذكرات، وروابط مهمة.
- **الإعدادات:** هوية الموقع، عبارة التمني، رقم الواتساب، فتح/إغلاق التسجيل، التفعيل المباشر،
  تقارير الطلاب، النسخ الاحتياطي، المزامنة، وإغلاق السنة الدراسية والأرشفة.
- **دليل التشغيل الكامل:** شرح تفصيلي لطريقة عمل النظام خطوة بخطوة داخل لوحة التحكم.

### بوابة الطلاب
- صفحة رئيسية عامة (إعلانات، لوحة شرف، ملفات، روابط، جدول المواعيد، اختبارات عامة).
- تسجيل طالب جديد + دخول بحساب خاص.
- عرض المواعيد والاختبارات والنتائج والتقرير الشخصي والحضور.
- حل الاختبارات الإلكترونية وإرسال الاستفسارات وطلبات النقل.

### تقنياً
- **Next.js 16 + React 19 + TypeScript** مع App Router.
- **Supabase** قاعدة بيانات ومصادقة — المصدر الوحيد للبيانات.
- **Tailwind CSS v4** وواجهة عربية كاملة (RTL) مع وضع ليلي/نهاري.
- **صفر تخزين محلي لبيانات الطلاب** — البيانات تُحفظ في السحابة فقط لحماية الخصوصية.

## إعادة تسمية الموقع باسم السنتر / المدرس

1. سجّل دخول المدير من `/login`.
2. افتح **الإعدادات ← الحساب والتخصيص ← هوية الموقع (اسم المدرس / السنتر)**.
3. اكتب الاسم (مثال: «أ/ محمد عبده» أو «سنتر النور للدروس الخصوصية») ثم اضغط **حفظ اسم الموقع**.

يظهر الاسم الجديد فوراً في كل مكان: عنوان المتصفح، الصفحة الرئيسية، صفحات الدخول،
اللوحة الجانبية، شاشة الترحيب، التذييل، ملفات PDF، أوراق الاختبارات والجداول، والتقارير —
ويُحفظ في السحابة ليظهر لكل الطلاب من أي جهاز.

## التشغيل محلياً

```bash
# 1) تثبيت الحزم
npm install

# 2) إعداد متغيرات البيئة
cp .env.example .env.local
# ثم املأ القيم من Supabase (Project Settings → API)

# 3) تشغيل بيئة التطوير
npm run dev
```

افتح `http://localhost:3000`.

> بدون إعداد Supabase يعمل النظام في وضع المعاينة فقط (لا تُحفظ البيانات ولا يصل إليها الطلاب).
> للإعداد الكامل خطوة بخطوة راجع **[SUPABASE_SETUP.md](./SUPABASE_SETUP.md)**.

## النشر

النظام جاهز للنشر على [Vercel](https://vercel.com). أضف متغيري البيئة
`NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_ANON_KEY` في
Project ← Settings ← Environment Variables ثم اربط المستودع وانشر.
